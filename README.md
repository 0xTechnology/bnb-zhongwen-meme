# bnb-中文模因

币安黄底，滚动字幕，一条走到 100% 的进度条。  
口号只有一句：一切都是为了 BNB。

在线页面：https://0xtechnology.github.io/bnb-zhongwen-meme/

## 这是什么

这是一个纯前端的中文 meme 页，没有钱包，没有合约，没有发币按钮。  
打开就能看，点一下「开始建设」，字幕往前滚，进度从 0 走到 100。

页面上写的是：

- 中文人生，就是把每一天都拿来建设。
- 中文 meme 的尽头，是 BNB。
- 币安链上，一切叙事都指向同一句话：一切都是为了 BNB。

仓库名用「模因」，页面文案用「meme」，两套叫法指的是同一件事：把一句能被反复转发的话，做成能打开的页面。

## 为什么做成这样

中文区的链上叙事，经常不是一份白皮书，而是一句能被截图的话。  
「建设」「人生」「一切都是为了某某」，这些句式本身就是传播单位。这个页面把这句式收成三个动作：

1. 看见黄底，认出币安色。
2. 看见顶栏字幕一直滚，知道这句话不会停。
3. 看见进度条走满，知道「建设」在这个页面里被做成了一次可点击的完成。

它不解释代币经济，也不引导交易。进度条到 100%，只代表这几行字播完了。

## 页面里有什么

顶栏是黑底黄字的滚动字幕，两段相同文案拼接，用 CSS 动画从右往左循环。  
中间是标题「中文人生」、副标题「建设 BNB」、口号「一切都是为了 BNB」。  
卡片下面是进度条。未点击时是 0%。点击「开始建设」后，按下面六句依次推进：

1. 中文人生启动
2. 建设模块加载
3. 连接币安叙事
4. 中文meme 注入
5. BNB 共识确认
6. 一切都是为了 BNB

每句大约停 450 毫秒，百分比按句数均分，最后停在「建设完成 · 100% · 一切都是为了 BNB」。再点一次会从 0 重走。

配色用币安黄 `#f0b90b` 做底，卡片和按钮用近黑色 `#0b0e11`，边框和阴影做成粗黑线，方便截图时一眼能认出来。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 结构：滚动字幕、标题、卡片、进度条、按钮 |
| `style.css` | 黄底、字幕动画、进度条条纹、按钮阴影 |
| `app.js` | 点击后逐句改文字，并把进度设到 100% |
| `README.md` | 本说明 |

没有构建步骤，没有依赖，没有 `package.json`。GitHub Pages 直接托管根目录。

## 本地打开

把三个文件放在同一文件夹，用浏览器打开 `index.html` 即可。  
字幕和进度都不需要服务器。

## 改文案

口号在 `index.html` 的标题和 `.slogan`。  
顶栏滚动内容在 `.ticker-track` 的两个 `<span>` 里，两段要保持一样，否则循环时会跳。  
点击后出现的六句在 `app.js` 的 `lines` 数组里，改完记得两段字幕一起改，避免页面和仓库说明各说各的。

## 部署

仓库 Settings → Pages → Branch 选 `main`，目录选 `/ (root)`。  
推送到 `main` 后，等一两分钟再刷新页面。浏览器如果还显示旧样式，用强制刷新，或在地址后面加 `?v=2`。

## 边界

这个仓库只放静态页。  
它不是发行平台，不保存地址，不连接 Flap、PancakeSwap 或任何钱包。  
如果以后要加合约地址，应单独写明来源，不要写进「建设完成」这句文案里，避免把一句口号读成募资说明。

中文人生启动。  
建设模块加载。  
进度走到 100%。  
一切都是为了 BNB。
